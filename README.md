# WP Certification Practice

A hands-on WordPress plugin project for practicing advanced WordPress development concepts.

## Development goals

The project will be used to practice:

- WordPress Coding Standards
- plugin architecture
- custom post types and taxonomies
- roles and capabilities
- Settings API
- REST API
- transients and caching
- WP-Cron
- block development
- Interactivity API
- internationalization
- debugging
- testing
- static analysis
- CI/CD

## Development environment

- WordPress 7.1.x
- PHP 8.4
- WordPress Studio
